# Project Arcade

Project Arcade is a cozy arcade management game developed with Unity.

## Game Idea

The player owns an old arcade.

Customers enter the arcade and spend coins on arcade machines.

The player can also play the arcade machines and earn bonus rewards based on their performance.

The ultimate goal is to build the best arcade in town.

## Current Features

- Player movement
- 2D arcade environment
- Basic project structure

## Planned Features

- NPC customers
- Arcade machines
- Mini games
- Economy system
- Arcade upgrades
- Progression system
- Daily reports
